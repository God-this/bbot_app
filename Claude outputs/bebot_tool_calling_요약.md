# 성경 Tool Calling 요약

## 한 줄 요약

답변에 성경 구절을 인용할 때 LLM이 기억으로 쓰지 않고, **DB에 넣어 둔 개역한글 원문을 도구로 조회해 그대로 인용**하게 만든 기능입니다.

- 브랜치: `refactor/tool-calling` (main 미머지)
- 핵심 파일: `backend/bible_tool.py`, `backend/load_bible.py`

## 동작 흐름

(여기에 `bebot_tool_calling_loop.png` 이미지 삽입)

1. `generate_node`가 시스템 프롬프트에 **성경 인용 규칙**을 붙여 메시지를 만듦
2. LLM 호출 — 1라운드는 도구 호출을 강제(`tool_choice="required"`)
3. LLM이 도구를 부르면 → DB 조회 → 결과를 대화에 붙여 다시 LLM 호출 (최대 3라운드)
4. 도구 호출 없이 답하면 그게 최종 답변 (SSE 스트리밍 / 캐시 저장)

> 문서 부족으로 fallback 답변이 나가면 이 루프를 타지 않아 도구도 호출되지 않습니다.

## 도구 2개

| 도구 | 용도 | 입력 | 제한 |
| --- | --- | --- | --- |
| `get_bible_verses` | 장절로 본문 조회 | 책, 장, (시작 절, 끝 절) | 최대 30절 |
| `search_bible` | 키워드로 구절 찾기 | 키워드, (책) | 최대 10건 |

- 책 이름은 `요`, `요한복음`, `John` 어떤 형태로 와도 1~66번으로 변환
- 없는 구절·오류는 `{"error": ...}`로 돌려주고, LLM은 그 구절을 인용하지 않음

## DB: `bible_krv`

| 컬럼 | 예시 |
| --- | --- |
| `book_no` | 43 |
| `book_abbr` / `book_name` | 요 / 요한복음 |
| `chapter` / `verse` | 3 / 16 |
| `text` | 하나님이 세상을 이처럼 사랑하사… |

- 한 절 = 한 행 (약 3만 1천 행), PK `(book_no, chapter, verse)`
- 적재: `python load_bible.py --file bible.txt` (먼저 `--dry-run`으로 확인)

## 인용 규칙 (프롬프트)

- 인용 전에 반드시 도구로 조회하고, 조회 결과를 한 글자도 바꾸지 않음
- 조회하지 않은 구절은 장절만 언급
- 형식: `"본문" (요한복음 3:16, 개역한글)`

## 테스트 결과

20문항 기준 인용 18건 중 **15건이 원문과 일치**, 평균 응답 **66초**.
